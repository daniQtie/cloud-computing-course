# System Information

## Linux Environment

The laboratory was completed using an Ubuntu 24.04 LTS environment in KillerCoda.

### Commands Used

```bash
cat /etc/os-release
uname -r
lscpu
free -h
df -h
```

### System Information

- **Operating System:** Ubuntu 24.04 LTS
- **Architecture:** x86_64
- **CPU:** Intel Xeon E312xx, 1 CPU
- **Memory:** Approximately 1.9 GiB total RAM
- **Disk:** Approximately 19 GiB total disk space
- **Virtualization:** KVM

## Notes

The commands above were used to inspect the operating system, processor, memory, and disk resources available in the cloud-based Linux environment.
