# Google Cloud Platform (GCP) Research

## Brief Overview
Google Cloud Platform (GCP) is Google's public cloud platform. It provides compute, storage, networking, databases, analytics, AI/ML, containers, and developer services.

## Global Infrastructure
Google Cloud uses regions and zones distributed across the world. Google Cloud currently lists 43 regions and 130 zones across six continents.

## Cloud Management Console
The **Google Cloud Console** is a web-based interface for creating, configuring, monitoring, and managing Google Cloud resources.

## Four Core Services
1. **Compute Engine** – Virtual machines.
2. **Cloud Storage** – Object storage.
3. **Virtual Private Cloud (VPC)** – Cloud networking.
4. **Cloud Identity and IAM** – Identity and access management.

## Three Advantages
1. Strong AI and machine learning capabilities.
2. Strong container and Kubernetes ecosystem.
3. High-performance global network infrastructure.

## Typical Enterprise Use Cases
- AI/ML applications
- Big data and analytics
- Kubernetes and containerized applications
- Global web applications
- Data platforms
- Software development
