# Mission Reflection

1. The cloud platform that impressed me the most is AWS because of its wide range of services and the flexibility it provides for different workloads. I found it useful that one provider can support basic virtual machines, storage, databases, networking, security, analytics, and other technologies. This makes AWS a practical platform for organizations with different technical requirements.

2. AWS, Azure, and GCP have many similarities. All three provide virtual machines, object storage, networking, identity management, databases, containers, monitoring, and other cloud services. They also use global infrastructure based on regions and zones, allowing organizations to deploy applications closer to their users and improve availability.

3. Business requirements are important when selecting a cloud platform. A company should consider its existing technology, budget, location, performance requirements, security needs, scalability, and technical skills. For example, Azure is a strong choice for an organization that already depends heavily on Microsoft technologies, while GCP can be attractive for AI, data, and Kubernetes workloads.

4. Acting as a Cloud Solutions Consultant taught me that choosing a cloud provider is not simply about selecting the most popular platform. The best choice depends on the actual problem that needs to be solved. I also learned that cloud services from different providers can be compared by matching their equivalent functions.

5. After completing this mission, my GitHub Cloud Computing Portfolio became more organized and useful. The research files, comparison tables, recommendations, and evidence give me a better record of what I learned. It also helped me practice explaining technical cloud concepts in a simple way that can be understood by both technical and business users.
