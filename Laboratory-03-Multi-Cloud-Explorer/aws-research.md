# AWS Research

## Brief Overview
Amazon Web Services (AWS) is a public cloud platform that provides compute, storage, databases, networking, security, analytics, AI/ML, and many other cloud services.

## Global Infrastructure
AWS organizes infrastructure into geographic Regions and Availability Zones. AWS states that each Region has at least three Availability Zones, helping customers design highly available applications.

## Cloud Management Console
The AWS Management Console is a web-based interface used to create, configure, monitor, and manage AWS resources and services.

## Four Core Services
1. **Amazon EC2** – Virtual servers for running applications.
2. **Amazon S3** – Object storage for files and data.
3. **Amazon VPC** – Networking environment for AWS resources.
4. **AWS IAM** – Identity and access management.

## Three Advantages
1. Very broad selection of cloud services.
2. Large global infrastructure and mature ecosystem.
3. Strong scalability and availability options.

## Typical Enterprise Use Cases
- Web and mobile applications
- Enterprise databases
- Backup and disaster recovery
- Data analytics
- AI/ML workloads
- E-commerce platforms
