# Microsoft Azure Research

## Brief Overview
Microsoft Azure is Microsoft's public cloud platform. It provides computing, storage, networking, databases, identity, AI, analytics, developer tools, and enterprise services.

## Global Infrastructure
Azure uses regions and geographies to provide cloud infrastructure around the world. Azure geographies help organizations meet data residency and compliance requirements.

## Cloud Management Console
The **Azure portal** is a unified web console for building, managing, and monitoring Azure resources and applications.

## Four Core Services
1. **Azure Virtual Machines** – Cloud-based virtual servers.
2. **Azure Blob Storage** – Object storage for unstructured data.
3. **Azure Virtual Network** – Private networking for Azure resources.
4. **Microsoft Entra ID** – Identity and access management.

## Three Advantages
1. Strong integration with Microsoft products and technologies.
2. Enterprise-focused identity, security, and management capabilities.
3. Broad global infrastructure and hybrid-cloud options.

## Typical Enterprise Use Cases
- Windows Server workloads
- Microsoft 365 and identity integration
- Enterprise applications
- Hybrid cloud environments
- Databases and analytics
- AI and machine learning
